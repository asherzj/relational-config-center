# 领域文档

## 阅读入口

- 项目通用术语见根目录 [CONTEXT.md](../../CONTEXT.md)；从 [CONTEXT-MAP.md](../../CONTEXT-MAP.md) 定位并阅读与当前主题有关的上下文词汇表。
- 阅读 [docs/adr/](../adr/) 及 `<context>/docs/adr/` 中与当前工作有关的决策。
- 上述领域词汇表、上下文地图或 ADR 不存在时直接继续，不提示缺失或预先建议创建。

## 使用约定

- 命名领域概念时使用相关词汇表中的术语，避免其明确排除的同义词。
- 新增已确认的领域概念时更新所属词汇表；实现细节和规划分别写入技术文档与设计说明。
- 前端共享的视觉、布局、组件和交互规范由 [web/DESIGN.md](../../web/DESIGN.md) 管理，按[设计文档约定](design.md)读取和维护；不把这些规则或任务进度写入领域词汇表。
- 与现有 ADR 冲突时，明确引用该决策并说明冲突和重新讨论的理由。
