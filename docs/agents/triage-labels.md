# Triage 标签

这些技能使用五个规范的 Triage 角色。本文件将这些角色映射到本仓库 Issue 跟踪器中实际使用的标签字符串。

| `mattpocock/skills` 中的标签 | 本跟踪器中的标签  | 含义                         |
| --------------------------- | ----------------- | ---------------------------- |
| `needs-triage`              | `needs-triage`    | 需要维护者评估此 Issue       |
| `needs-info`                | `needs-info`      | 等待报告者提供更多信息       |
| `ready-for-agent`           | `ready-for-agent` | 规格完整，可交给离线智能体   |
| `ready-for-human`           | `ready-for-human` | 需要由人类完成实现           |
| `wontfix`                   | `wontfix`         | 不会处理                     |

当技能提到某个角色时（例如“添加可交给离线智能体的 Triage 标签”），请使用上表中对应的标签字符串。

如果实际使用的标签词汇不同，请编辑右侧一列以保持一致。
