# 项目管理记录

本项目的项目级进展记录维护在 [Notion 项目管理页面](https://app.notion.com/p/3ca8544cc98980559f27e17f2c94cbaf)。

## 与 GitHub Issues 的分工

- GitHub Issues 用于跟踪具体工单和规格说明，操作约定见 `docs/agents/issue-tracker.md`。
- Notion 项目管理页面用于汇总项目级进展和已交付功能。

## 功能完成后的更新要求

每完成一个可以独立交付和验收的完整功能，必须主动更新上述 Notion 页面，并在更新后再向用户报告功能完成。更新时沿用页面现有结构，至少反映：

- 完成的功能及当前状态；
- 主要交付结果和验证情况；
- 相关 Issue、Pull Request 或仓库文档；
- 尚存风险或后续工作（如有）。

小范围排查、讨论、仅产出方案以及尚未通过验证的中间实现，不视为完整功能。

如果当前环境无法访问或编辑 Notion，不得声称已经更新。应在交付说明中明确指出阻塞，并提供可直接写入项目管理页面的更新内容。
