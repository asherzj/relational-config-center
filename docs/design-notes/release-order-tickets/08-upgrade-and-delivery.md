## 验收标准

- [ ] 存量迁移可重跑、可检测未完成状态并按文档恢复；控制数据不完整时拒绝开启业务写入，不自动发放管理权。

- [ ] 真实申请、审批、发布账号完成浏览器编辑→草稿→审批→发布→查询→回滚申请→审批→反向发布，覆盖刷新/登录恢复与冲突保留输入。
- [ ] 正式浏览器目标及 CI 确实执行发布单关键路径；所需数据库/浏览器缺失不能静默跳过为通过。
- [ ] 完整 Go/Web/真实 MySQL/浏览器回归和架构/契约检查通过，每张工单已有自己的局部证据；最终验证不替代缺失的工单验证。
- [ ] 所有状态的历史、差异和永久身份在重启及账号资料变化后可追溯，无物理删除或自动清理。
- [ ] 检查 T5（#52） 已删除旧写路由/调用、T6（#53） 已删除单条阶段限制，无假通知成功或隐藏兼容入口。
- [ ] 为 AC-001～AC-048 汇总精确证据，完成固定基点的 Standards/Spec 评审，同步领域、ADR、公开操作及迁移文档。
