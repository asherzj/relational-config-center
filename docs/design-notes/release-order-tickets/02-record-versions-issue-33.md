## 验收标准

- [ ] 查询内容与记录版本来自同一一致性快照，版本作为独立元数据无损返回。

- [ ] 新增、存量缺失版本的首次写入、失败回滚、删除后同 id 重建均保持并发身份连续。

- [ ] 原有规则快照、实时 Schema、权限、自动字段和真实操作人继续生效。
