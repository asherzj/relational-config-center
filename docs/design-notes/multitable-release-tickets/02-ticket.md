## 父工单

Part of #81：https://github.com/asherzj/relational-config-center/issues/81

## 要构建什么

管理员定义每表零组或一组管控键；编辑者保存草稿即取得主键和业务键占用，分页增量保存、删改及排序使用整单版本。不同单冲突时看到表、占用单号和负责人；同单共享目标按完整引用关系释放。

## 验收标准

- [ ] 真实字段定义支持单/组合键，遵循数据库等价语义，NULL参与且区别空字符串；拒绝无法在草稿保存时确定的值。
- [ ] 禁止自增、生成及发布时自动字段作为管控键；新增默认字段显式填写，修改省略字段从真实旧值推导。
- [ ] 有未结束单明细引用表就禁止新增/删除/修改定义，包括没有具体目标的自增草稿；与保存竞争不能绕过。
- [ ] 空草稿不占用，新增新值、修改旧新值、删除旧值；保存/删改与占用同事务，无自动过期。
- [ ] 分页只提交本次增删改并检查整单版本；同表同主键拒绝重复，数据库等价表示不能绕过。
- [ ] A/B改A/C原子取得C、释放不再需要的B，失败保留原内容、占用和页面输入。
- [ ] 取消、拒绝、完结、回滚成功的已有路径必须能释放所有类型的占用，管理员可取消遗留草稿。
