## 验收标准

- [ ] 从明细选择表、追加、分页增量编辑到冻结审批都支持多表；跨表同ID可共存，同表主键仍唯一。
- [ ] 多表合计最多1000条，1001条拒绝，不自动拆单；调整发布单链路旧字节预算，不修改无关功能限制。
- [ ] 一事务按冻结正序发布、倒序回滚，不自动重排依赖；只支持保存时已知的跨明细引用，不支持引用尚未生成的自增ID。
- [ ] 全部表/记录版本、实际结果、执行摘要、主单、通知和占用一致提交；锁定顺序不能改变业务执行顺序。
- [ ] 自增ID生成后保护实际ID；任何表失败不能留下其他表已提交的结果。
- [ ] 各阶段保留占用，取消/拒绝/完结跨表释放，原有独立正向审批及当前权限不变。
- [ ] 主单列表、多表详情、三种明细内容、全局排序、错误定位、桌面390px及键盘路径完整；分页不改变审批和执行范围。
