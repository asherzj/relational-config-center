## 实现执行方式

功能基线为从 main cd5df58 创建的 `codex/release-orders`。每张工单从已验证的累计基线创建独立分支/worktree，记录固定基点；不得混用主 checkout 的未提交改动。每次实现使用新的完整工单上下文，重新读取正文/评论、领域文档和 ADR。当前环境若不能自动提供干净实现上下文，按 flow-feature 要求停在工单边界并提供下一张准确调用方式，不把上一单的偶然上下文带过去。

通过当前工单必要检查与 code-review 后才允许提交/推送；远端拒绝立即停止，不自动重写历史。功能最终核对全部验收证据、临时结构和上下文，再更新 Notion 项目总表。中间工单完成不声称整个发布单功能完成，也不把阶段分支当成已经完成强制审批的生产版本。
