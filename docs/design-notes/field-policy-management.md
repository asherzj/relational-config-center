# 表字段规则管理（#74）

设计基准：`web/DESIGN.md` 与 main `8b5cd85` 的表规则分配和编辑抽屉；沿用中性灰画布、正式 shadcn 控件及现有未保存保护。

管理员在表规则分配每行点击「字段配置」，打开同一页面的640px抽屉。抽屉上方显示真实表名、保存范围与启用说明；真实字段选择器始终显示字段名和配置状态。选择一个字段后分为显示、查询、录入三组；字段切换保留整表输入，底部「保存全部字段配置」原子保存。未配置字段保持未配置，点击「配置此字段」才加入完整提交列表；停用保留全部原值。字段名只读，不可手写创建。

显示组维护中文名称、说明、顺序与列表可见性；查询组维护可查询及明确运算符；录入组使用原生控件选择，静态选项按「名称／实际值」逐行编辑及添加删除，预填通过「未配置／指定值／NULL」明确区分。所有值保留字符串，不将数字转成浮点数。

读取失败显示重试；保存错误保留输入；结果未知锁住再次保存，先只读核对当前服务器配置，再明确返回编辑。表单不因后台刷新或同账号恢复而重置。切换页面、关闭抽屉和浏览器离开沿用未保存保护；失去管理员角色后表单只读。

桌面与390px手机验收：入口→选真实字段→中文名称、控件和两行选项→保存→关闭重开完整回显→停用→重开；测试未保存关闭、键盘标签、焦点恢复、长字段名换行与页面横向溢出。手机选项三列调整为单列；抽屉内容独立滚动、底栏操作保持可达。

下游查询、录入与显示消费属于#75～#79，本工单管理界面明确说明目前保存的交互规则将在后续接入这些页面。
