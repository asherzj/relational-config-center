## T1：管理员维护多类型发布流程模板

**阻塞于：** 无；从已合并 Goose、多表正式基线开始。

**交付什么：** ADMIN 在正式目录中创建、查看和编辑多份常规/应急模板，使用受约束的节点表单，并处理常规停用、应急保护、重复编码和并发冲突。两表中的模板定义结构随本切片的公开管理能力交付。

**验收用例：** AC-001、AC-002、AC-003、AC-004、AC-005。采用父规格的 Given/When/Then，以上用例由本切片承担唯一主要交付责任。

**验证证据：** 节点规则模块只证明合法组合和参数边界；HTTP＋真实 MySQL 证明授权、编码唯一、审计与版本/幂等；浏览器证明管理入口、编辑、失败输入保留及基础键盘操作。本切片立即通过自身正式新装、向前升级、只读就绪与控制表保护检查；受影响回归为账号授权、规则管理与受保护控制表访问。

**必须立即验证的风险：** 不得把应急模板保护仅做成禁用按钮；旧请求重推不能创建第二份模板。审批节点只表达正式表审批能力的类型，不接入旧全局 APPROVER。

**临时结构与退出条件：** 不引入业务流程兜底、双写或兼容层。配置管理已可独立验收，但不会宣称实例与执行已接通。

## T2：为每张受管表配置常规与应急模板

**阻塞于：** T1。

**交付什么：** ADMIN 在表设置为两种方式选择模板；不同表可选择或复用同类型模板。初始化和新增受管表得到有效应急关联，关联替换保持有效，常规可停用。新增关联表及其完整性约束、管理接口和界面一起交付。

**验收用例：** AC-006、AC-007、AC-008。采用父规格的 Given/When/Then，以上用例由本切片承担唯一主要交付责任。

**验证证据：** HTTP＋真实 MySQL 证明每表每类型唯一、类型一致、初始化/启用与关联原子性、并发切换及禁止解绑；浏览器证明表选择、当前模板效果、错误恢复与常规停用。本切片立即验证新增关联结构的正式新装、向前升级、只读就绪与控制表保护；受影响回归为表规则创建、启用、停用和结构就绪。

**必须立即验证的风险：** 重跑初始化不能覆盖已选模板；数据库失败不能产生受管但无应急关联的表；应急保护不能扩大为禁止停用整张表规则。

**临时结构与退出条件：** 无异步补齐、临时默认读取或第二套关联来源；未接入执行不等于应急执行已交付。
