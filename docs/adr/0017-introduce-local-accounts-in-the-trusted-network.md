# Introduce local accounts within the existing trusted-network boundary

本地账号迭代引入由系统管理凭据的终端用户账号，并允许自行注册；部署仍只服务单个组织，运行于本机或可信内网。选择内建账号而非先接入企业身份源，是为了先交付独立可用的注册、登录、登出、会话恢复、过期、撤销和未登录访问保护；保留统一的当前身份接口，企业身份接入、角色授权和持久审计仍按后续工作包推进。

自行注册成功即启用账号，所有账号均可使用现有规则管理与配置数据管理能力，并继续受到表规则约束。这个阶段刻意不区分使用者的管理权限，因此能够访问注册入口的人可以自行取得管理台使用资格；这项取舍依赖已经确认的单组织可信网络边界，后续角色授权应另行设计。

业务接口统一要求用户登录会话，同次移除代理注入共享部署 Token 的路径与免认证开关，健康检查继续无认证。选择一次性切换而非并存旧认证，是为了避免共享凭据或匿名请求绕过账号准入与会话撤销；原有脚本调用必须迁移。

本决策取代 [ADR-0003](./0003-single-tenant-trusted-network-first-iteration.md) 中“不建立终端用户模型”、部署级 Bearer Token 与 loopback 免认证的约定，保留其单组织、可信网络及不承诺公网或多租户的边界。真实 Operator 归因的调整见 [ADR-0018](./0018-attribute-authored-changes-to-stable-account-ids.md)。
