# Reapprove rollbacks and reject stale publications

审批针对提交时冻结的表结构、变更规则和配置变更内容；执行时记录版本、表结构或规则执行语义已变化就拒绝发布，保留申请供重新确认。相比按当前值直接覆盖，这需要维护独立于业务表的记录并发版本并将其与业务变更一起提交，换取审批期间的修改不被旧申请静默覆盖；它取代 ADR-0016 对受管配置记录暂时接受 last-write-wins 的约定，不把规则目录的历史版本或并发保护纳入本期。

回滚创建有关联的反向发布单并重新经过他人审批，执行前再次验证原发布的结果未被后续修改；不得以回滚之名覆盖较新的配置。原发布及操作历史保留，回滚生成新的变更记录和发布版本；取消只终止尚未发布的意图，不能代替反向发布。当前实现已接通重新审批的反向发布，详见[回滚契约](../admin-release-rollbacks.md)；分支验证和上线授权仍分别记录。

[ADR-0023](./0023-keep-published-orders-open-for-quick-rollback.md) 增量调整发布后的完结与恢复时机：普通回滚只从已完结普通单申请，成功反向结果直接结束；待完结快速回滚的免审批例外由后续工单实现。

后续[ADR-0025](./0025-multitable-drafts-reserve-targets-and-record-executions.md) 将占用前移至草稿、支持多表整单，并以原单内成功执行记录替代独立回滚单；完结后不再允许回滚。该目标决策已确认，交付由规格 #81 跟踪，本文其余未被替代的正向审批与一致性规则继续有效。
