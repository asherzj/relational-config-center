# Require Release Orders for Managed Table record changes

为让配置记录在实际写入前经过人工审批，所有受管配置记录的新增、修改和删除统一通过发布单执行，并关闭原有可直接写入业务记录的 HTTP 通道；仅补追踪记录或按表保留绕过审批的写入口均不满足本次已确认的流程。首版在现有单个 Managed Data Source 和受管表上交付，不前置建设 Environment 或 Page Model；配置记录治理与规则目录管理保持区分，规则管理本身不经过发布单审批。

发布申请人、审批人和执行人的身份沿用 ADR-0017 的本地登录会话及 ADR-0018 的永久 Account ID；新增查看、编辑、审批、发布、管理角色，任何人包括 ADMIN 均不得审批自己的单据。这会取代 ADR-0017 当前所有账号具有相同管理能力的阶段性取舍，具体角色授予和迁移按发布单规格实施；本决策的角色与正式发布切换已在当前实现接通，操作及维护边界见[发布单升级指南](../admin-release-upgrade.md)。

当前工作只交付管理台正式发布、取消、回滚及其持久化变更和通知记录，灰度、Server/Client 实际分发及版本大盘另期交付；历史开源候选规格中的代理身份头、Environment/Page Model 前置和完整运行时范围不得直接套用到这一期。
