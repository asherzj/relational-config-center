## 合并结果

Admin 同时装配模板、表关联和审批角色服务；发布审批保留按表的正式资格校验。表管理同时提供查看、字段配置、发布流程、审批角色四个入口，管理目录同时保留发布流程模板、角色管理和账号角色。#102 的版本、原请求结果及手动原样重推语义保留。节点草稿快照由后续 #103 实现，现有逐表审批安排仍在提交时固定、成员资格实时计算。

历史接管边界固定为版本 5。正式迁移 1～7 的 14 个 SQL/manifest 文件与 #94 逐字节相同；候选 8、9 的 SQL 与 #102 相同。两个尚未部署的候选累计 manifest 从正式版本 7 的真实 MySQL 顺序执行生成，完整包含 27、28 张控制表。新增验证发现并修复旧候选遗漏六张审批控制表的就绪检查缺口。版本 7 的角色、成员、永久引用、表分配、原请求结果及业务事实在升级后保留，历史接管、部分执行恢复、新装等价和只读就绪仍通过。

为避免 ADR 编号冲突，模板决策改名为 `docs/adr/0027-configure-release-workflows-with-stable-templates.md`，当前领域链接同步；已交付的 `0026-authorize-approval-by-table-roles.md` 保留。历史证据的旧路径仍指其原提交，不改写历史产物。
