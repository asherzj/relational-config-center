## Focused checks and corrections

- The first external unmanaged-startup acceptance failed for the expected reason:
  the prior Admin started successfully (`/private/tmp/rcc-goose-t3-red.log`).
  The new read-only gate passed that test in 13.135 seconds.
- Initial readiness matrix passed in 38.308 seconds. After adding bootstrap
  metadata checks, older unconfirmed-history detection, running-process old-version
  regression and independent schema equality, all four targeted top-level tests
  passed in 53.455 seconds (`/private/tmp/rcc-goose-t3-readiness-final.log`).
- The wiring run passed existing account schema failures, historical upgrade,
  migration-table protection, usable/idempotent fixture and Policy audit cases.
  The frozen-data loader initially attempted a generated-column insert, then
  exposed exported SQL DATETIME formatting and JSON presentation differences.
  These fixture setup issues were corrected without weakening before/after SQL
  value snapshots or public response comparison. AC004 passed independently in
  13.825 seconds (`/private/tmp/rcc-goose-t3-adoption-verified.log`).
- The first real Compose build completed both images and reached Admin after
  successful migration and fixture, but the harness did not catch a transient
  HTTP `RemoteDisconnected` during startup. The readiness poll now handles this
  connection error within the same bounded deadline; that failed run and cleanup
  remain in `/private/tmp/rcc-goose-t3-compose/`. A second harness attempt exposed host proxy routing for loopback and Python 3.9 socket timeout compatibility; the probe now explicitly connects directly to its own loopback endpoint and catches bounded connection errors. Both failures remain recorded. The six Compose stages then passed in `/private/tmp/rcc-goose-t3-compose-verified/`; the final image rerun after review fixes also passed all six stages in `/private/tmp/rcc-goose-t3-compose-reviewed/`.

## Architecture and current-entry retirement

`TestAdminHTTPCompositionCannotRunSchemaMaintenance` rejects maintenance calls
from the normal HTTP composition root. The existing HTTP/Application and release
transaction boundary tests continue to run. The new current-entry source check
rejects revival of the former init directory or references in Compose, browser
acceptance and README. Full generic layer-graph enforcement remains the previously
documented repository limitation; no such new guarantee is claimed.

Outside this verification report, `rg '001-schema' README.md admin deploy scripts docs`
finds only the dated pre-change discussion (linked to its historical commit) and the original
2026-09-07 acceptance report. Neither is a current installation caller. Current
runbooks, ADR-0001/0015/0024, architecture, technical baseline and historical
upgrade guidance now describe the Goose/fixture/Admin sequence and explicit
adoption/recovery.
