# 按表角色审批与通知中心验收报告

对应规格 [#92](https://github.com/asherzj/relational-config-center/issues/92)，交付工单 #93～98。验收日期：2026-09-11；目标基线 main f701438f。原始日志、截图和逐项哈希档案保留在本地，不随本次 PR 发布。

## 交付内容

- 角色与人员多对多关联；管理员可维护角色、成员及逐表审批角色。
- 提交时固定角色分配，审批时核对当前成员资格；各表任一合格成员通过，全部表通过后才可发布。
- 无合格角色成员时由独立 ADMIN 接手；任何人不可自审，已完成决定和当时来源保留。
- 通知中心提供待我审批、我发起的、我已处理、全部审批；个人未读与待办分开，已读只确认实际看到的进度。
- 审批及发布全过程的结果提醒与业务、原请求结果共同提交；原请求重推不会重复执行或提醒。
- 正式迁移版本 9 退出旧 APPROVER 当前授权，保留其他权限位、会话、授权历史及既有审批事实。
