本切片交付 ADMIN 发布流程模板目录、创建/查看/编辑、常规启停与删除、应急保护、稳定编码和类型、版本并发、审计以及所有写入的持久请求结果。模板定义保存受约束的 `node_list` JSON 数组；模板级 `monitor_list` 固定为空数组。同一发布类型允许多份模板。
