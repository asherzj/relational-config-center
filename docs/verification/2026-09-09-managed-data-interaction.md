# 配置编辑与导航交互验证

本次改动基于已合并 MR #66 的 `main`（`8f8ba73`），包含记录编辑、NULL 选择、Change Set 草稿区以及导航顺序的调整。

## 交付行为

- 修改记录直接带入并提交全部可编辑字段；主键、数据库计算列和服务器自动填写字段不进入修改内容。新增记录继续保留字段省略语义。查询列元数据增加可选的 `generated` 标识。
- 非 NULL 字段以独立标签显示“不允许 NULL”，不提供无效的 NULL 勾选。可为空字段显示“设为 NULL”，选中后禁用输入并显示“已设为 NULL”；取消后恢复之前输入，NULL 与空字符串保持区别。
- Change Set 的标题、对比表、草稿去向、底部操作分区；标题输入、字数、已有草稿入口对齐，窄屏上下排列。表格可以键盘横向滚动，保存草稿为主操作。
- 主导航依次为配置管理、表配置管理、平台人员管理；保留人员管理的管理员权限限制。移除发布单与配置内容管理标题下指定的说明文字。
