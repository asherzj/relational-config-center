## Hypothesis and exact dependency scope

The hypothesis is that the aggregate engine update from Playwright 1.62.1 / WebKit 26.5 revision 2336 to 1.63.0 / WebKit 26.6 revision 2359 changes this native failure's occurrence. The comparison keeps the same native Linux amd64 job definition, app/backend source, original accounts case, signal whitelist and fixed first-failure-stop loop. It runs on a new GitHub-hosted runner of the same platform class, not the identical prior VM. There are at most 12 rounds, one unchanged 600-second limit per case, and one unchanged 15-minute job limit including setup. No failed attempt is retried. A pass only supports a bounded version effect; it does not identify a specific engine fix or invalidate the 2336 SIGSEGV.

The precise official bases are [343e13bf (1.62.1)](https://github.com/microsoft/playwright/blob/v1.62.1/browser_patches/webkit/UPSTREAM_CONFIG.sh) and [4d05d732 (1.63.0)](https://github.com/microsoft/playwright/blob/v1.63.0/browser_patches/webkit/UPSTREAM_CONFIG.sh). A bounded history check found two nearby null protections: [c7e77855, KeyframeEffect asynchronous animation weak reference](https://github.com/WebKit/WebKit/commit/c7e77855c828), and [b77f86b8, ImageBuffer without PlatformDisplay in a service worker](https://github.com/WebKit/WebKit/commit/b77f86b890e1). Neither is established as this compositor-thread fault: the first concerns asynchronously scheduled animation work without a matching stack; the second has a different process/scenario. No precise fix attribution or disabling of animation/compositing is justified.

The candidate was resolved once in `/tmp` using `pnpm add --save-dev --save-exact --lockfile-only playwright@1.63.0`. `fixture/candidate.patch` is the exact reviewed difference; CI does not dynamically resolve a new dependency graph. `fixture/original.sha256` and `candidate.sha256` strictly identify the two complete dependency files before/after application. The only direct dependency change is Playwright. Lock changes affect Playwright and playwright-core versions/integrities, plus removal of **fsevents@2.3.2**, the Darwin-only optional dependency referenced exclusively by old Playwright and no longer needed by 1.63.0. Other dependency graph entries, including fsevents@2.3.3, are unchanged. `dependency-graph-check.json` records the structural comparison.
