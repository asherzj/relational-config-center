### 导航测试时序修正

迁移后并行运行曾复现：确认放弃草稿后，测试只检查 router 的 location 就立刻调用下一次后退。此时 React 尚未提交目标页面，旧表单还没取消未保存状态注册，后退再次触发离开确认，因此测试等不到预期表单。

修正仅在现有导航测试中增加对目标页面标题的等待，再发起下一次 POP。没有增加业务导航延时。临时重复 12 次的测试在同样并行套件中由 1 次失败变为全部通过（207 项）；移除重复与调试代码后保留原有 196 项正式测试。jsdom 补齐 Radix 所需的 ResizeObserver 与 matchMedia，复杂整页 user-event 流程的单项超时上限设为 10 秒；元素等待仍用 Testing Library 默认值。
