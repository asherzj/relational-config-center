# T4：免审批快速回滚与可靠恢复

状态：已交付；[#63](https://github.com/asherzj/relational-config-center/issues/63) 已关闭。实现与验证见[验收索引](../../verification/2026-09-09-release-detail-acceptance-index.md)。

## 父工单

Part of #59：https://github.com/asherzj/relational-config-center/issues/59

## 要构建什么

发布人员在审阅恢复差异和原因后，无新审批整单恢复待完结发布；完结后的普通审批回滚继续有效。两类回滚都终止原单和反向结果，释放目标且不允许继续反向发布。

## 验收标准

- [x] AC-004：无需新审批整单恢复；保存真实执行人、结果和原因，原单已回滚且目标释放。
- [x] AC-005：明确失败且整单不生效；原状态、业务值、版本及占用不出现部分结果。
- [x] AC-006：至多一个有效结果；原请求返回原业务结果，不重复恢复。
- [x] AC-003：另一位当前有发布权限者可快速回滚或完结；仅查看、编辑或审批者被拒绝。
- [x] AC-015：快速回滚必须先有恢复预览和原因；完结说明释放目标及关闭快速回滚；取消确认无业务变化。

## 验收用例

主要交付：AC-003, AC-004, AC-005, AC-006, AC-015。采用父规格的 Given/When/Then，不引入未确认需求。
