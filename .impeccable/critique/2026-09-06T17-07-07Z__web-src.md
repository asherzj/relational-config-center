# 第一性原理评审与本次风格优化

本报告基于改造前的正式 Web 四个路由、规则详情与替换表单。两个独立评估先分别完成，再综合设计判断与浏览器证据。当前唯一数据库表分配未启用；记录查询结果、编辑和写入后回查的建议依据源代码，未操作真实配置数据。

## 评审标准

配置管理应使用户快速确认四件事：选对配置对象、看懂当前行为、理解本次变化、知道执行结果。优先减少判断错误和跨页记忆，其次减少查找与重复输入，视觉服务于这条操作路径。

产品基础扎实：查询规则与变更规则具有受保护生命周期；表规则分配只选择符合条件的定义；记录变更保留完整前后对照、NULL 与空字符串区分和写入后精确回查。这些机制应保留。

## 五项优先发现

1. **P1：规则选择缺少行为摘要。** 表规则详情和替换表单主要展示编码，未展示允许新增、修改、删除、默认排序与自动填写字段。合法候选仍可能选错业务效果。建议选择旁就地展示效果、跳转详情；替换时核对当前和新规则的差别。源：`web/src/features/table-policies/TablePolicyDrawer.tsx`。后续可用 impeccable clarify/shape 深化。
2. **P1：首次任务缺少下一步，技术说明占据主要入口。** 当前已有未启用分配，配置内容空状态仍需用户自行关联侧栏。建议按缺失原因导向相应分配、规则或表；沿用既有规则定义与表分配分离，不改变 ADR-0016。此次已补“前往表规则分配”入口并重写四页任务说明；更细分的原因导航仍可后续完善。
3. **P1：记录编辑把请求构造交给用户。** 每个字段默认不包含，必须先勾选才能修改；统一文本框增加格式记忆成本。建议直接呈现当前值，跟踪用户实际改动，保留“保持原值、设置值、设为 NULL”的精确语义。必填与默认值必须由可靠元数据提供，不能仅凭 nullable 推断。源：`web/src/features/managed-data/ManagedRowEditor.tsx`。此项仅代码评估，未随视觉改造重写。
4. **P2：宽表把操作藏在右侧，视觉主次弱。** 改造前在 1456px 桌面，变更规则表内容 1280px、容器 1134px，操作不可直接看到。名称、编码、类型和审计信息各占一列；次级文案实测对比度约 3.81:1，行操作目标仅约 24 × 22.5px。此次合并相关字段、固定操作列、增大操作目标、统一字体层级和文字颜色，1280px 桌面变更目录可完整显示。
5. **P1：安全退出和键盘模态语义不完整。** B 实测详情抽屉打开时 Tab 可进入背景导航；代码也没有未保存离开保护。建议统一抽屉与确认框焦点管理，仅在有未保存修改时保护退出。此次修复窄屏关闭导航仍留在键盘路径的问题；抽屉焦点与未保存保护仍需后续实现。源：`web/src/components/ui/Drawer.tsx`。

## 角色与认知负荷

首次使用者容易卡在“已有数据但配置页不可用”；高频操作者反复查找规则、编码及行操作；键盘用户会遇到弹层背景仍可聚焦。认知成本集中于跨页记忆规则效果、把业务字段翻译为请求字段、同时扫读过多平级属性。应在每次决策旁提供相关信息，并将规则治理和日常查改记录串成连续任务。

## 已实施的视觉方向

用户明确选择“现代轻盈：更多留白、柔和色彩、较强层次”。实施覆盖共享主题、应用壳、四个正式页面，以及沿用共享样式的表单、抽屉、对话框和反馈。

- 雾灰底色、白色面板、低饱和青绿；统一圆角、细分隔、文字层级和区块留白。
- 导航加入统一线性图标，去掉无交互的展开箭头；移除固定“就绪”和无功能的环境按钮，展示真实的单数据源模式。
- 规则名称与编码合并；审计信息收拢；固定操作列。数据库表概览改为可扫描列表行。
- 表单减轻嵌套面板，抽屉保留独立滚动和固定操作区；手机导航、单列表单与局部滚动统一处理。
- 视觉规范归档在 `web/DESIGN.md`。

确定性扫描改造前只有 `overused-font` 警告，定位旧 `styles.css:2` 的 Inter 字体栈；这是风格启发式，不足以解释实际可用性。修改后手动扫描结果为空。浏览器只读接口不允许 overlay 注入，采用原生截图、DOM 和几何数据作为证据。

验证：共享工作区的 Web 15 个测试文件、104 项测试通过；提交前将本次界面改动从并行规则重构中独立提取，独立分支的 13 个测试文件、100 项测试、类型检查和生产构建通过；实查 1280px 桌面列表、表规则详情，以及 390px 窄屏导航、新建草稿表单。未启用真实表、未提交配置写入；未实测本地无数据状态下无法到达的记录结果页面。样式验证不代表完整无障碍审计通过。

后续优先：先做规则效果摘要，再优化记录编辑语义，并补齐抽屉焦点和未保存退出保护。用户已回答本次视觉方向问题，无需重复选择。
