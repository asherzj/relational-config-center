# 配置中心产品形态原型

抛弃式 UI 原型，用来回答：当产品分别以“结构化配置中心”和“关系型配置中心”为终态时，前端的核心工作台应该有什么不同？

```bash
cd web
npm run prototype
```

打开：

- `http://127.0.0.1:4173/prototype/config-center/?variant=structured`
- `http://127.0.0.1:4173/prototype/config-center/?variant=relational`

页面底部的原型切换器和键盘左右方向键可以切换两个版本。所有数据与操作都只保存在内存中。
