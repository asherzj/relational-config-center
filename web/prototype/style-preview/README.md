# 查询规则样式预览

一次性视觉方案，在独立原型内比较灰蓝、石墨灰和青绿。`base.css` 固定保存 2026-09-07 的应用样式基线，`preview.css` 提供配色覆盖；静态预览无需 Tailwind 编译，也不随正式应用后续样式变化。所有记录为内存示例，刷新页面恢复；其他导航仅用于展示页面上下文。

从 `web` 目录运行 `pnpm prototype`，打开：

http://127.0.0.1:4173/prototype/style-preview/?variant=blue

支持底栏或左右方向键切换配色（`blue` / `graphite` / `teal`）、关键词搜索、状态筛选、详情抽屉，以及内存中的草稿新建与编辑。

此目录保留当时的配色对比方案，不代表正式应用的当前样式；正式界面规范见 [web/DESIGN.md](../../DESIGN.md)。
